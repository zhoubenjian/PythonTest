# 模型 API 调用 · 骨架练习（W05）

目的：不借助任何 SDK 和框架，用 `requests` 裸调 HTTP，把「一次大模型调用」从请求到响应完整摸一遍。
后面 W06～W12 的 RAG 全建立在这条最基础的链路上，这里不清楚，后面全是黑盒。

## 前置

- 仓库根目录 `.env` 里有 `DEEPSEEK_API_KEY`（已配置，勿提交）
- 已安装：`requests`、`python-dotenv`
- 公共配置见 [config.py](config.py)，不需要改

## 规则

1. **按顺序做**：01 → 02 → 03，每个文件跑到验收 PASS 才进下一个
2. **先自己写**，写完运行 `python 01_basic_call.py` 看验收输出
3. 卡住超过 20 分钟才来问，问的时候说清楚「卡在哪一行、报了什么错」
4. 每一步的坑记到本文末尾「踩坑记录」——这是面试素材
5. 密钥永远只从环境变量读，不要 `print` 出来，不要写进代码

## 步骤与验收标准

| # | 文件 | 任务 | 验收 |
|---|------|------|------|
| 1 | [01_basic_call.py](01_basic_call.py) | 非流式调用一次，解析正文与 usage | content 非空；usage 三个字段 > 0 且守恒 |
| 2 | 02_stream.py | 流式接收，逐块打印 | 首块到达明显早于整体结束；拼接结果非空 |
| 3 | 03_structured.py | 让模型输出 JSON + 错误处理 | 稳定拿到可 `json.loads` 的对象；401/超时/非法 JSON 都被拦住 |
