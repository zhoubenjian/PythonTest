# 维度格式
标量（0 维）
就是一个数。比如气温 26°C。在 NumPy 中 shape 显示为空元组 ()。

向量（1 维）
一串有序的数。比如一天中每小时的气温记录。Shape 为 (n,)，n 是元素个数。

矩阵（2 维）
一张表格，有行和列。比如一周七天、每天 24 小时的气温表。Shape 为 (行数, 列数)。

张量（3 维及以上）
多层数据叠放。比如全国 300 个城市、每个城市一周 7 天、每天 24 小时的气温。Shape 为 (城市数, 天数, 小时数) 即 (300, 7, 24)。


# 点乘（内积，标量乘法）：
a · b = a @ b = np.dot(a, b)

# 模长（|a| ||a|| 两种表示方式通常等价）：
# L1 范数（曼哈顿距离：绝对值和数）
# L2 范数（欧氏距离：平方和数），默认L2范数！！！
|a| = ||a|| = np.linalg.norm(a)

# 矩阵夹角
# 锐角（θ < 90°） 正值；
# 直角（θ = 90°） 0；
# 锐角（θ > 90°） 负值；
cosθ = a · b / ||a||·||b|| = a @ b / (||a||·||b||)

# 归一化
任何非零向量除以自己的模长，得到长度为1的单位向量
u = a / ||a|| = a / np.linalg.norm(a)

# 向量余弦相似度
向量归一化后：||a|| = ||b|| = 1时
余弦相似度(cosθ) = a · b / (||a||·||b||) = a · b


# 矩阵乘法
充要条件：左矩阵的列(n) = 右矩阵的行(n)，A(m,n) x B(n,p) = C(m,p)       
！！！通常情况不满足组交换律：AB ≠ BA！！！


# 矩阵转置
行列互换：
    原来 (i, j) 位置的值，经过转置后到了 (j, i) 位置。 形状从 m×n 变成 n×m

关键性质：
    AA^-1 = I
    (AB)^-1 = B^-1A^-1 
    (AB)^T = B^TA^T


# 伴随矩阵(Adjointate matrix)
    伴随矩阵adj(A)是矩阵A代数余子式矩阵的转置


# 逆矩阵(只有方阵才有逆矩阵！！！)
    AB = BA = I
    (AB)^-1 = B^-1A^-1 
    可逆矩阵也叫非奇异矩阵（Non-singular matrix），不可逆的叫奇异矩阵（Singular matrix）
    如果矩阵可逆，其逆矩阵是唯一的

    对于方阵A（以下命题等价）：
    A可逆 <=> det(A)≠0 <=> rank(A)=n <=> A的行（列）向量线性无关 <=> 齐次方程Ax=0的只有零解 <=> 对任意b，方程Ax=b有唯一解


# 特殊矩阵(只有方阵才有特殊矩阵！！！)
    -单位阵（Identity matrix）：
        主对角线全是1，其余全是0，乘以任何矩阵，等于该矩阵

    -对角阵（Diagonal matrix）：
        只有主对角线上有值，每个维度独立缩放

    -对称阵（Symmetric matrix）：
        关于主对角线对称，转置=自身
        ！！！特征值全是实数，特征向量相互正交！！！对称矩阵在优化和统计中极其有用——协方差矩阵和 Hessian 矩阵都是对称矩阵。


# 矩阵秩（Rank）
    秩 = 行数 = 列数，满秩，唯一解（方阵）
    秩 = 列数 < 行数，列满秩，可能无解或唯一解（超定方程组）
    秩 = 行数 < 列数，行满秩，无穷多解（欠定方程组）
    秩 < 行数 且 秩 < 列数，可能无解或无穷多解

    先看矩阵是几行几列的。秩的最大值不可能超过行数和列数中较小的那个数
    这叫“满秩上限”，如果实际秩等于这个数，就叫满秩
        比如 3×5 的矩阵，秩最多是 3
        比如 2×2 的矩阵，秩最多是 2

    找“全零行”（看行与行是否成比例）
        把矩阵写成行向量的形式，看看有没有哪一行是其他行的倍数
        A = [1  2]
            [2  4]
        第二行 (2, 4) 正好是第一行 (1, 2) 的 2倍
        说明这两行是“重复信息”，只有 1 行是独立的
        秩 = 1（因为有效行只有 1 行）

    化简为行阶梯形矩阵
        把矩阵的行进行行变换，使所有非零行的主元都在主对角线上
        非0行个数就是秩的值

# 奇异值分解（Singular Value Decomposition）
    A(m x n) = U(m x m正交矩阵) * S(m x n对角矩阵) * V^T
    
    U：m x m正交矩阵，列为左奇异向量，两两单位正交
    S：m x n对角矩阵，对角元奇异值满足σ1≥σ2≥...≥σr>0(主对角线元素是奇异值)，剩余位置填 0
    V：n x n正交矩阵，列为右奇异向量，两两单位正交，V^T的行是右奇异向量的转置

    适用于所有矩阵
