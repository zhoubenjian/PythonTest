# 离散随机变量
    概率函数：P(X = x) = P(X = x | θ)
    伯努利分布：P(X = 1) = θ
    二项分布：P(X = k) = C(n, k) * θ^k * (1 - θ)^(n - k)


# 连续随机变量
    正态分布：P(X = x) = (1 / √2πσ^2) * exp(-(x - μ)^2 / (2σ^2))
    指数分布：P(X = x) = λ * exp(-λx)
