归一化：把数据缩放到一个固定的范围，通常是 [0, 1] 或 [-1, 1]。

标准化：把数据调整为均值为0，标准差为1的标准正态分布。



用归一化的场景：
    算法依赖距离（如KNN、K-Means、SVM），且数据本身边界明确（如图像像素值 0-255）。
    需要使用梯度下降且特征范围差异极大（归一化能让收敛更快）。
    需要保证输出在特定区间（如某些激活函数的输入）。

用标准化的场景（绝大多数情况）：
    数据服从或近似正态分布。
    算法假设数据呈正态分布（如线性回归、逻辑回归、LDA）。
    降维（PCA）前必须标准化，否则方差大的特征会主导主成分。
    数据存在明显异常值（标准化能降低其影响）。



不确定时，优先用标准化（StandardScaler）——它更稳健，适用范围更广。

只有在以下情况才特意用归一化：
    数据本身就是有界物理量（如百分比、像素值）。
    使用KNN或K-Means且特征单位不一致。
    深度学习中某些需要固定输入范围的网络（如使用Sigmoid/Tanh作为输出层）。
